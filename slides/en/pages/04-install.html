Installing

Four kinds of packages
from three places.

Install scripts can run 7za, zstd, avbctl and resetprop. When an install writes over the recovery partitions, Skyward can flash itself back.

Ways to install

  • Install from internal storageChoose a package or image in internal storage
  • Install from a USB driveConnect a USB drive through OTG
  • Install from a computerRun adb sideload on the computer
